# 禅意桌面 · Zen desktop

**简体中文** | [English](README.en.md)

留片刻宁静。

Windows 轻交互动态桌面壁纸，以禅意、放松和留白为方向。当前实现「赏鱼」：锦鲤缓游、甩尾转身、聚拢觅食，小雨落入水面，荷叶与荷花安静地浮在池边。画面实时绘制，不使用视频。

![赏鱼场景预览](docs/preview.png)

当前版本 **0.3.8**。源码镜像：[GitHub](https://github.com/SSYNG/zen-desktop) · [Gitee](https://gitee.com/ssy_kr/zen-desktop)。

## 功能

- 三类锦鲤，可选 2—3 种、6—32 尾，调整基准游速。每尾鱼具有不同游速，慢游间偶尔冲刺和急转。
- 单击空白桌面投喂一颗鱼食，附近鱼群加速接近；近处侧向鱼饵会触发减速、弓身蓄力、甩尾转向与更大的水波，鱼嘴触碰后才消费鱼饵，随后鱼群散开。
- 调整鱼数量时，新鱼从画面外游入，减少的鱼游出画面后离开，其他鱼保持原有状态。
- 小雨开关：水滴、水冠与飞散水珠配合传播、叠加、衰减的水面涟漪。
- 可选日历：阳历、农历、星期，以及最近节日或节气的倒计时。
- 分开的壁纸设置与软件设置；通透面板、悬停浮起、渐入渐出过渡。
- 用户自选本地音乐、声音开关与音量。未选择音乐时静音。
- 启动直接挂到桌面，设置默认关闭；双击空白桌面切换图标显示，正常退出时显示桌面图标。
- 绘制跟随刷新回调，无固定帧率选项；桌面回调停顿时使用备用帧时钟。实际帧率仍受硬件与窗口调度影响。

「听雨」「观海听涛」「林海雪原」「竹林幽径」目前仅作为场景占位。

## 运行

支持 Windows 10 / 11 x64。内置 Electron / Chromium，不依赖 WebView2；桌面桥需要 .NET Framework 4.8。

1. 解压完整便携包，保留同目录所有文件。
2. 双击 ZenDesktop.exe，壁纸进入主显示器桌面。
3. 通过右上角按钮或托盘打开设置。关闭设置面板不会退出壁纸。
4. 从托盘菜单或设置底部选择退出。

默认 16 尾锦鲤、三种配色、基准速度 0.8 倍，日历开启，小雨与声音关闭。设置自动保存到 %APPDATA%\ZenDesktop-Electron；自定义音乐保存在该用户数据目录的 IndexedDB 中。

便携包约 **156 MiB**，解压后约 **371 MiB**。本地 dist/ 仅保留最新 0.3.8 与次新 0.3.7 的目录和 ZIP；构建产物不随源码提交，克隆仓库后需要自行构建。本轮未发布远程 Release 安装包。

普通窗口预览（不挂载桌面、不改变图标）：

    .\ZenDesktop.exe --preview

## 开发

需要 Windows、Node.js **22.12 或更新版本**、npm，以及 Windows 的 .NET Framework C# 编译器。已在 Node.js 22.13.1 环境验证。生成图标另需 Python 与 Pillow，普通构建直接使用已提交图标。

    npm ci
    npm run preview       # 浏览器预览：http://127.0.0.1:5173
    npm test              # 鱼群模拟与音乐生命周期测试
    npm run build         # 编译桌面桥并打包 Windows x64 便携程序
    npm run desktop       # 桌面桥生成后，运行 Electron 桌面程序

首次安装 / 构建会下载 Electron 运行时。网络环境需要时，可在执行 npm ci 前设置 ELECTRON_MIRROR；未设置时使用官方下载来源。请勿关闭证书校验。

若本机 npm 配置禁用了安装脚本，需要执行 `node node_modules/electron/install.js` 后才能运行开发桌面窗口。

构建输出：

    dist/v0.3.8/ZenDesktop-win32-x64/ZenDesktop.exe
    dist/ZenDesktop-Electron-0.3.8-win-x64.zip

重新打包同一版本前请先退出该版本，否则 Windows 可能锁定程序文件。浏览器预览仅验证画面与交互；桌面挂载、图标与托盘需在 Windows 程序中验证。

## 实现结构

| 目录 | 内容 |
| --- | --- |
| electron/ | 主窗口、独立设置窗口、托盘、隔离 IPC 与备用帧时钟 |
| native/ | C# / Win32 桌面挂载、鼠标坐标映射与图标控制 |
| web/simulation.js | 鱼群运动、局部避让、觅食、冲刺与急转 |
| web/renderer.js | 独立 Canvas 鱼体、程序化皮肤与雨滴 |
| web/water-surface.js | Three.js GPU 水波与透明水面层 |
| web/ | 设置、农历日历、音乐与平面水彩背景 |
| assets/ | Windows 图标及 PNG 图标 |
| scripts/ | 构建、预览服务器与图标生成脚本 |
| tests/ | 模拟与音乐测试 |

鱼体与水波分别绘制，避免把整屏鱼体画布每帧上传成 WebGL 纹理。荷叶与荷花固定在背景中，鱼为程序化 2.5D 身体变形，没有完整三维模型。显卡不支持所需水面功能时回退到 Canvas 涟漪。

## 兼容性与当前边界

- 目前只覆盖主显示器，不支持各显示器独立配置。
- 腾讯桌面整理等软件可能覆盖壁纸层；经本轮验证，退出腾讯桌面整理后壁纸能显示。
- 请勿同时运行多个历史版本。Explorer 重启后可从托盘尝试重新挂载。
- WorkerW / Progman 挂载依赖 Explorer 的非公开桌面结构，Windows 更新可能影响兼容性。
- 正常退出会显示图标；强制结束或崩溃可能无法执行清理，可通过桌面右键「查看 → 显示桌面图标」恢复。
- 尚未实现开机启动、全屏应用暂停、系统休眠恢复、多场景、安装器及长时间功耗调优。

15 项自动测试覆盖食物吸引和消费、鱼群散开、边界稳定性、游速差异、自主急转、小雨数量限制、自定义音乐释放、侧向甩尾追食、鱼嘴碰撞，以及增减数量与快速反向调整。桌面实际显示依赖人工验证；模拟状态变化不等同于屏幕画面更新。
